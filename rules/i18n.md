# Localization (I18N-xx)

Rules for user-visible text in Arabic / English UIs. The I18N reviewer (`agents/reviewer-i18n.md`)
applies them to the changed lines only.

The projects use one of two mechanisms; the reviewer works out which from the code:

| Stack | Text in code | Translation files |
|---|---|---|
| Angular (ngx-translate) | `{{ 'KEY' \| translate }}`, `[attr.x]="'KEY' \| translate"`, `translate.instant('KEY')`, `translate.get('KEY')`, `marker('KEY')` | JSON per language, e.g. `src/assets/i18n/<area>/ar.json`, `en.json`. Nested objects: `{ "A11Y": { "SEARCH": "..." } }` is key `A11Y.SEARCH`. |
| ASP.NET MVC | `@Localizer["Key"]`, `@SharedLocalizer["Key"]`, `@Resources.Key`, `IStringLocalizer<T>["Key"]`, `[Display(Name = "Key", ResourceType = ...)]` | `.resx` per language, e.g. `Resources/Shared.resx`, `Shared.ar.resx`: `<data name="Key"><value>...</value></data>`. |

## Rules

| ID | Severity | Check | Fix |
|---|---|---|---|
| I18N-01 | Warning | User-visible text written literally in a template or view: text nodes, and the `placeholder`, `title`, `alt`, `aria-label`, `aria-placeholder`, `label` values, button and option text. | Add a key to every language file and use it through the project's mechanism. |
| I18N-02 | Warning | A literal chosen by language in code: `currentLang == 'ar' ? 'بحث' : 'Search'`, `lang === 'en' ? ... : ...`, `@(isArabic ? "..." : "...")`. | Replace the condition with one key. If both strings already exist as a key, reuse it. |
| I18N-03 | Warning | User-visible text written literally in TypeScript / C# / JS: toast, alert, confirm and dialog messages, page titles, validation messages, text that is bound into the template or a live region. | Build it with `translate.instant('KEY', params)` / `Localizer["Key"]`. |
| I18N-04 | Error | A key used on a changed line that is missing from a language's translation files (the user sees the raw key). | Add the key to every language file that lacks it. |
| I18N-05 | Error | A key added or renamed on a changed line of one language file that is missing from another language's file for the same area (e.g. in `common/en.json` but not `common/ar.json`). | Add the key with its translation to the other language file. |
| I18N-06 | Error | The same key twice in one JSON object, or two `<data name>` with one name in a `.resx` file, on a changed line. Only the last one is used. | Keep one entry with the right value. |
| I18N-07 | Warning | A sentence built by joining translated pieces or a translated piece and a variable (`translate('A') + name + translate('B')`), so the word order can't change per language. | One key with a parameter: `'KEY' \| translate: { name: x }` / `{{name}}` in the value. |
| I18N-08 | Warning | A value added on a changed line that is empty, is the key itself, or is in the wrong language (an `ar` value with no Arabic letters where the `en` value is a normal word, or an `en` value in Arabic). Brand names, codes, numbers and symbols are not this. | Write the real translation. |

## How the reviewer uses this file

- Report only findings on a line in `changedLines`. For a key on a changed line, look it up in the
  translation files of every language (`translations` in target.json); a key found in **any** file of
  a language counts as present for that language, since the reviewer can't see which files a module
  loads.
- A key built at runtime (`'STATUS.' + code`, `Localizer[name]`) can't be checked: don't report it.
- Not user-visible, so not I18N: CSS classes, ids, routes, URLs, `data-*` and test ids, enum and API
  values, log and `console` text, comments, code that is commented out, `.spec.ts` files, and strings
  passed only to code (keys of a map, event names).
- Not text to translate: brand and product names, numbers, units, symbols and punctuation alone,
  icons, file extensions, sample values in a `placeholder` such as an email or URL format.
- Language names in a language switcher are written in their own language on purpose (`English`,
  `العربية`): not a defect.
- One finding per rule per line. When one line has I18N-02 and the same text also breaks I18N-01,
  report only I18N-02.
