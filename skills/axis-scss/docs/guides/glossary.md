## Terms

| Term                | What it means                                                                                                                                                                                                                                                                  | Link for more                                                                           |
|---------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------|
| **aggregator**      | A `common/` file, such as `_components.common.scss`, that gathers one kind of shared file behind a single `@use` line for every page that needs it.                                                                                                                            | [Common](../segments/common.md)                                                         |
| **allowlist**       | The limits on `theme/custom.theme.css`: no custom property, and `body` is the only element selector allowed.                                                                                                                                                                                        | [Theme — custom.theme.css](../segments/theme.md#the-custom-theme-file)                  |
| **architecture owner** | The person who owns this architecture and manages everything about it — Khaled Mohamed.                                                                                                                                                                                      | [README](../README.md)                                                                  |
| **AXIS**            | The name of this architecture: Architecture for eXtensible Intelligent Styles.                                                                                                                                                                                                 | [README](../README.md)                                                                  |
| **build route**     | One of the two supported ways to compile SCSS to CSS: the Web Compiler 2022+ extension or the `sass` npm package.                                                                                                                                                              | [Build — The two build routes](./build.md#the-two-build-routes)                         |
| **bundle**          | The compiled output of one entry file: one stylesheet, whichever build route produced it.                                                                                                                                                                                      | [Performance](./performance.md)                                                         |
| **component**       | A self-contained, reusable UI piece that follows BEM naming and carries the `c-` prefix.                                                                                                                                                                              | [Components](../segments/components.md)                                                 |
| **control module**  | A standalone JavaScript widget with its own markup — a datepicker, a Select2-style list, a data grid. Its block carries the `ctrl-` prefix; its styles, including any CSS the widget ships, live in its control module file, and no other file styles or overrides a `ctrl-` block. | [Modules — Control Modules](../segments/modules.md#control-modules)                     |
| **entry file**      | One of the file kinds the build compiles directly, rather than reaching through `@use`. This glossary does not repeat the list.                                                                                                                                                | [Build Documentation — Entry files](./build.md#entry-files)                             |
| **folder index**    | A folder's `_index.scss`: a partial that gathers the folder's files — with `@forward` in Tools, with `@use` elsewhere — so one `@use` reaches them; never compiled on its own.                                                                                                                                                     | [Best Practices — Folder Index Files](./best-practices.md#folder-index-files)             |
| **identity values** | The per-client hue, saturation and lightness in `theme/colors/colors.base.theme.css`; what differs from one client to the next.                                                                                                                                                | [Theme — Files Overview](../segments/theme.md#files-overview)                           |
| **layout scope**    | The layout name dot-joined ahead of a Layout partial's suffix, marking which layout owns it — `.app.` in `_header.app.layout.scss`. Files in `layout/shared/` carry no scope.                                                                                                   | [Naming Conventions — Suffix per segment](./naming-conventions.md#suffix-per-segment)   |
| **legacy stylesheet** | Whatever CSS a migrating project already ships, frozen from the day its migration starts and shrunk as pages move off it.                                                                                                                                                     | [Migration — The legacy stylesheet](./migration.md#the-legacy-stylesheet)               |
| **library module**  | A module that overrides one component of an external framework or library, in its own `_<vendor-component>.<library>.module.scss` — `_modal.bootstrap.module.scss` → `.m-modal`. Its `m-` class sits beside the vendor class on the vendor element. A plain `.module.scss` holds no vendor selector. | [Modules — Vendor Override Scoping](../segments/modules.md#vendor-override-scoping) |
| **locale build**    | One prebuilt build of a library per locale, named `<library><major>.<locale>.min.css`, side by side in the library's `packages/` folder. Every build carries its locale.                                                                                                       | [Packages — File structure](../segments/packages.md#file-structure)                     |
| **main program / sub-program** | A main program is a group of pages, such as the items under one side-menu entry; each page goes in `pages/<main-program>/<sub-program>/<page-name>/`.                                                                                                                       | [Pages — File structure](../segments/pages.md#file-structure)                           |
| **module**          | Styling for the interaction between two or more components placed together, for a library module, or for a control module — not a generic reusable piece.                                                                                                                      | [Modules](../segments/modules.md)                                                       |
| **object**          | A flat structural pattern that carries no meaning on its own; it defines a shape or arrangement, and whatever is placed inside supplies the meaning. It is not a component: a component means something by itself, and an object has no purpose until something is placed in it. | [Objects — What an object is](../segments/objects.md#what-an-object-is)                 |
| **page-local**      | Describes an import route, not a location: a file `@use`d directly by the page entries that need it, rather than through a `common/` aggregator. The file itself never moves out of its segment folder.                                                                        | [Common — Placement Rule](../segments/common.md#placement-rule)                         |
| **partial**         | A Sass file that is never compiled on its own. On the Node route a leading underscore is what marks it as one; on the Web Compiler route it simply has no entry of its own in `compilerconfig.json`.                                                                           | [Build Documentation — Entry files](./build.md#entry-files)                             |
| **promotion**       | Moving a file's `@use` line out of the page entries that carry it and into the matching `common/` aggregator, once it is used by enough pages to cross the shared threshold. The file itself does not move, only the import.                                                   | [Common — Placement Rule](../segments/common.md#placement-rule)                         |
| **script hook**     | A `js-*` class a script only queries and never adds or removes; it carries no style and is not a state class.                                                                                                                                                                  | [Rules — State Management](./rules.md#state-management)                                 |
| **segment**         | This architecture's own name for its unit of organization. The published methodologies it draws on name theirs differently; the README's note on words draws that distinction.                                                                                                 | [Segment Structure](../README.md#segment-structure-in-authoring-order)                  |
| **shared**          | Describes an import route, not a location: a file `@use`d once from a `common/` aggregator instead of separately from each page that needs it. The file itself never moves out of its segment folder.                                                                          | [Common — Placement Rule](../segments/common.md#placement-rule)                         |
| **Ships CSS**       | The segment puts rules on the page, whether or not it compiles: Packages (prebuilt vendor CSS) and Theme (plain CSS) ship CSS without compiling.                                                                                                                               | [Segment Structure](../README.md#segment-structure-in-authoring-order)                  |
| **standalone page** | A page outside any main program, such as a login page, in `pages/standalone/<page-name>/`.                                                                                                                                                                                     | [Pages — File structure](../segments/pages.md#file-structure)                           |
| **state class**     | An `is-*`/`has-*` class the markup carries from first load and no script ever changes, or a `js-*` class JavaScript adds or removes at runtime. A `js-*` class a script only queries is a script hook, not a state class.                                                                                                                        | [Rules — State Management](./rules.md#state-management)                        |
| **state page**      | A page that reports a state, such as an error or no-permission page, in `pages/state/<state-page>/`.                                                                                                                                                                           | [Pages — File structure](../segments/pages.md#file-structure)                           |
| **token**           | A CSS custom property declared in the Theme segment: a color, a font family, or a size or weight step.                                                                                                                                                                         | [Theme — Token sets and their values](../segments/theme.md#token-sets-and-their-values) |
| **variant class**   | A project-named class for a variation, such as a primary or small button. It is not state, and carries a prefix the project chooses (R-01).                                                                                                                                    | [Rules — State Management](./rules.md#state-management)                                 |
| **vendor override** | A scoped override of an external framework's component-level selector, written in that component's library module. Never routed through a control module.                                                                                                                     | [Modules — Vendor Override Scoping](../segments/modules.md#vendor-override-scoping)     |
